### Added
- Initial release of IONOS DNS module
- IONOS Hosting Developer API integration
- DNS zone listing
- DNS record management (A, AAAA, CNAME, TXT, MX)
- Add, update, and delete DNS records
- API key format handling with automatic encoding
- Dashboard integration with SVG icon
