## [1.1.1] - 2026-04-06

### Added
- Initial release of Qdrant Knowledge Bank module
- Qdrant vector database integration
- Centralized AI knowledge base
- IT documentation storage and search
- Runbook management
- Semantic vector search capabilities
- Payload filtering by category and tags
- Dashboard integration with SVG icon

## Module Information

- **Name**: qdrant
- **Description**: Zentrale KI-Wissensbank auf Basis von Qdrant. Speichert und durchsucht Fachwissen, IT-Dokumentation und Runbooks per semantischer Vektorsuche mit Payload-Filterung nach Kategorie und Tags.
- **Author**: Ninko Team
