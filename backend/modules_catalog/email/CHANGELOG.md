# Changelog

All notable changes to this module will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-04-06

### Added
- Initial release of Email module
- SMTP email sending with STARTTLS support
- IMAP email reading with SSL support
- Basic authentication (App passwords)
- OAuth 2.0 (MSAL) for Microsoft 365
- HTML email formatting
- File attachment support (with upload endpoint)
- Email search with complex filters
- Email move and delete operations
- File upload for attachments (max 25MB)
- Dashboard integration with SVG icon

## Module Information

- **Name**: email
- **Description**: Email client for Ninko. Send via SMTP and read/manage via IMAP. Supports Basic Auth and MSAL (Microsoft 365 OAuth2)
- **Author**: Ninko
