# Changelog

All notable changes to this module will be documented in this file.

## [1.1.2] - 2026-04-06

### Added
- Initial release of FritzBox module
- TR-064 protocol integration for AVM FRITZ!Box routers
- WAN status monitoring with external IP detection
- Bandwidth monitoring (up/down speeds)
- WLAN status and guest WLAN management
- Network device listing (LAN/WLAN connected devices)
- Smart Home (DECT) device control
- Smart socket control capabilities
- Routing keywords for alternative spellings ("Fritz!Box", "ipadresse", "fritz-box")
- Dashboard integration with SVG icon

## Module Information

- **Name**: fritzbox
- **Description**: Integration und Steuerung von AVM FritzBox Routern via TR-064 und AHA
