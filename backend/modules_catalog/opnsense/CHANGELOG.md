## [1.1.1] - 2026-04-06

### Added
- Initial release of OPNsense module
- Firewall management via REST API
- System/interface/gateway status monitoring
- Firewall and NAT rule CRUD operations
- DHCP lease visibility
- Service restart and log access
- TLS verification override for self-signed certificates
- Dashboard integration with SVG icon
