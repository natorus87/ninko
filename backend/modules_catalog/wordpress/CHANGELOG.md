## [1.1.1] - 2026-04-06

### Added
- Initial release of WordPress module
- WordPress REST API v2 integration
- Site info and update visibility
- Plugin lifecycle management (search/install/activate/deactivate/update/delete)
- Page and post CRUD operations
- Categories and tags management
- User management
- Media library access
- Site settings management
- WooCommerce support
- Dashboard integration with SVG icon
