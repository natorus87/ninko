## [1.1.1] - 2026-04-06

### Added
- Initial release of Home Assistant module
- Home Assistant REST API integration
- Entity state reading
- Service calls for device control
- Entity listing and searching
- Device and entity detail inspection
- Smart home device control (lights, switches, sensors)
- Support for multiple entity types
- Dashboard integration with SVG icon
