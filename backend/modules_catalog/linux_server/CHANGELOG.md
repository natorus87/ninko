# Changelog

All notable changes to this module will be documented in this file.

## [1.1.1] - 2026-04-06

### Added
- Initial release of Linux Server module
- SSH-based server management
- Password authentication support
- RSA key authentication support
- Remote command execution
- Service management (systemd)
- System monitoring (journalctl, df, top)
- Cron job management
- Package management (apt)
- Firewall management (iptables)
- Web server management (Apache, Nginx)
- Database management (MySQL, PostgreSQL)
- Dashboard integration with SVG icon

- **Name**: linux_server
- **Description**: Linux Server Management via SSH — commands, services, monitoring, files
